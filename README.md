# Misi Anti-Korosi

Game edukatif Redoks-Korosi (3 misi, SDG 9 / SDG 12 / ESD 2).

## Menjalankan
Buka `index.html` di browser, atau jalankan server lokal:

    python3 -m http.server 8000

lalu buka http://localhost:8000

## Catatan
- Semua kode (HTML, CSS, JS, ilustrasi SVG) ada di satu berkas `index.html`.
- Di luar claude.ai, papan skor memakai penyimpanan lokal browser (localStorage), jadi hanya terlihat di perangkat yang sama.
- Kode guru bawaan: `guru123` (Menu Papan Skor > Guru). Ganti setelah dipakai.
- Font Lilita One dan Nunito dimuat dari Google Fonts, jadi perlu internet; tanpa itu tampil dengan font cadangan.
